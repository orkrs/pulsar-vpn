## 🚀 Следующие шаги

### Тестирование установщика

1. **Установка:**
   ```powershell
   # Запустите установщик
   .\target\release\bundle\nsis\pulsar-ui_0.1.0_x64-setup.exe
   ```

2. **Проверка установки:**
   - Приложение должно быть установлено в `%LOCALAPPDATA%\Programs\pulsar-ui\`
   - Ярлык должен появиться в меню Пуск
   - Проверьте работу VPN функциональности

3. **Проверка логов:**
   - Логи должны создаваться в `%LOCALAPPDATA%\PulsarVPN\logs\`
   - Проверьте наличие файлов `pulsar-daemon-*.log` и `pulsar-ui-*.log`

### Распространение

1. **Для тестирования:** Используйте NSIS установщик (меньше размер)
2. **Для продакшена:** Используйте MSI установщик (лучше для корпоративных сред)
3. **Подпись:** Рекомендуется подписать установщики цифровой подписью для избежания предупреждений Windows Defender

## 🔧 Повторная сборка

Для повторной сборки используйте скрипт:
```powershell
.\build.ps1
```

Или вручную:
```powershell
# 1. Сборка демона
cargo build --release -p pulsar-daemon

# 2. Копирование демона
Copy-Item "target\release\pulsar-daemon.exe" -Destination "pulsar-ui\src-tauri\binaries\pulsar-daemon.exe" -Force

# 3. Сборка UI
cd pulsar-ui
bun run build
bun run tauri build
```
