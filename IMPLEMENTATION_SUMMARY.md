- ✅ Логирование ошибок с контекстом (пути, коды ошибок)

## 🔧 Технические детали

### Зависимости:
```toml
# Демон и Tauri
tracing = "0.1"
tracing-subscriber = { version = "0.3", features = ["env-filter", "fmt", "time"] }
tracing-appender = "0.2"
time = { version = "0.3", features = ["formatting"] }
uuid = { version = "1.0", features = ["v4"] }  # только для Tauri
```

### Формат логов:
```
[2025-02-22T10:30:45.123Z] [INFO] [pulsar-daemon::main] toggle_connection RPC called request_id=abc-123-def
```

### Расположение:
- Демон: `%LOCALAPPDATA%\PulsarVPN\logs\pulsar-daemon-YYYY-MM-DD.log`
- UI: `%LOCALAPPDATA%\PulsarVPN\logs\pulsar-ui-YYYY-MM-DD.log`
